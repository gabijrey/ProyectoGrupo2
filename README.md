## 📖 Sobre el Proyecto

**ComicLook** es una aplicación web diseñada específicamente para la valoración de cómics y mangas. Nace como una alternativa a las redes sociales tradicionales y foros, centrándose exclusivamente en ofrecer un espacio dedicado a las reseñas y opiniones del mundillo "friki", sin implementaciones innecesarias.

Nuestra misión es proporcionar una plataforma común donde los usuarios tengan sus obras favoritas al alcance de la mano, puedan opinar sobre ellas y generen una comunidad sólida de personas que comparten la misma pasión por la lectura ilustrada.

## 🎯 Público Objetivo

La plataforma está pensada para diferentes tipos de lectores dentro de la comunidad de habla hispana:
* **Coleccionistas:** Usuarios que buscan llevar un registro de sus lecturas y descubrir dónde adquirir nuevas obras.
* **Críticos:** Personas que disfrutan debatiendo, escribiendo reseñas extensas y buscando visibilidad para sus opiniones.
* **Lectores casuales:** Usuarios que quieren iniciarse en este mundo o no saben qué leer a continuación y buscan recomendaciones basadas en popularidad o géneros.

## ✨ Funcionalidades Principales

ComicLook incluye las siguientes características clave para ofrecer una experiencia personalizada:

* **Gestión de Usuarios:** Permite el registro, inicio de sesión, así como la edición y borrado del perfil personal.
* **Búsqueda y Filtros:** Cuenta con un buscador integrado para encontrar cómics, mangas y otros usuarios, apoyado por filtros avanzados (autor, título, año de lanzamiento, etc.).
* **Sistema de Reseñas (CRUD):** Los usuarios registrados pueden crear, leer, actualizar y eliminar sus propias reseñas y valoraciones de las obras.
* **Listas de Favoritos:** Capacidad para añadir o eliminar cómics y mangas de una biblioteca personal de favoritos.
* **Interacción de la Comunidad:** Sistema social para enviar solicitudes de amistad, bloquear usuarios indeseados o reportar a quienes infrinjan las normas.
* **Sistema de Suscripciones:** Planes "Premium" y "Autor" que otorgan beneficios exclusivos como verificación, mayor peso en las reseñas, experiencia sin anuncios y posicionamiento de obras destacadas.

## 🛠️ Stack Tecnológico

El proyecto está construido bajo una arquitectura web que separa el cliente del servidor:
* **Frontend (Cliente):** Interfaz gráfica desarrollada con HTML5 y CSS3, utilizando JavaScript para la manipulación del DOM y la comunicación con la API.
* **Backend (Servidor):** Lógica del servidor y creación de la API construida con PHP.
* **Base de Datos:** Sistema de gestión de bases de datos relacionales MySQL para almacenar la información de usuarios, obras, reseñas y suscripciones.
